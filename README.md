# Sistema de Registro e Inicio de Sesión - Proyecto Integrador Web Multimedia

Este repositorio contiene la implementación del módulo de autenticación (Registro e Inicio de Sesión) con persistencia de datos en base de datos, desarrollado para la asignatura **Proyecto Integrador Web Multimedia**.

El objetivo principal de este desarrollo es proporcionar una interfaz web funcional, responsiva e interactiva que gestione el flujo de acceso de usuarios mediante validaciones de seguridad e integración con el almacenamiento de datos.

## Características Principales

* **Formulario de Registro:** Captura y validación de datos de nuevos usuarios en el cliente y servidor.
* **Módulo de Inicio de Sesión:** Verificación de credenciales almacenadas en la base de datos.
* **Persistencia de Datos:** Integración con base de datos relacional/NoSQL para la gestión de usuarios.
* **Manejo de Sesiones:** Control de estado de usuario autenticado mediante cookies/tokens de sesión.
